# Extended Cogwheels (UNOFFICIAL) — NeoForge 1.21.1

An unofficial NeoForge 1.21.1 port of Create: Extended Cogwheels by Rabbitminers.

## Features

- Half-shaft and shaftless cogwheels in small and large sizes.
- Material changes for copper, iron, brass, and steel ingredients.
- Hand crafting, Create deploying, and Create cutting recipes.

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1.x
- Create 6.0.10 or a compatible 6.x build
- Flywheel 1.x

## Runtime test

A dedicated server test with NeoForge 21.1.219 and Create 6.0.10 loaded the mod, reached the server-ready state, saved the isolated test world, and shut down cleanly. Client launch and rendering have not been tested.
